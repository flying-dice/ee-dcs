# DCS engine investigations

Reproduction material and detailed application workarounds belong here. Reports
are local drafts, not statements that Eagle Dynamics has confirmed a defect.

- [Runtime FARP helicopter spawning](runtime-farp-spawning/README.md): dynamic
  helicopter activation, authored-FARP controls, recycling, and mission-generation
  workaround. Related project issue: [#3](https://github.com/flying-dice/ee-dcs/issues/3).
- [Airbase ground obstructions](airbase-ground-obstructions/README.md): runway
  infantry blocked a Vaziani recon departure; targeted removal was followed by
  taxi and takeoff. Includes evidence and preventive-clearance work in progress.

Keep minimal missions, exact scripts and relevant bounded observations with each
report. Do not add entire personal DCS logs or claim that an API return proves an
aircraft became active. Record version and simulation time for every comparison.
